# Universal AI

**[Abrir o guia Universal AI](https://limaronaldo.github.io/universal-ai/)**

[![Publicação no GitHub Pages](https://github.com/limaronaldo/universal-ai/actions/workflows/pages/pages-build-deployment/badge.svg?branch=main)](https://github.com/limaronaldo/universal-ai/actions/workflows/pages/pages-build-deployment)

O Universal AI é um guia independente, escrito em português, para quem quer estudar inteligência artificial por conta própria. Reúne cursos, aulas, livros e ideias de projetos e mostra como os assuntos se conectam. Você pode começar por programação em Python, aprender a treinar e avaliar modelos ou se aprofundar em temas como visão computacional e modelos de linguagem.

## Como usar o guia

- **Se está começando**, siga o roteiro de estudos em seis fases. Ele ajuda a escolher o que estudar primeiro e quando avançar. [Ver roteiro de estudos](https://limaronaldo.github.io/universal-ai/#roteiro)
- **Se já tem um objetivo**, explore as trilhas por tema. Em Stanford, por exemplo, CS230 é uma opção para aprender a treinar redes neurais, enquanto CS224U explora como avaliar a compreensão de linguagem por um modelo. [Explorar trilhas por tema](https://limaronaldo.github.io/universal-ai/#trilhas)
- **Se procura uma universidade**, use o índice por instituição. Há seções de Stanford, Harvard, MIT, Carnegie Mellon, UC Berkeley, Princeton e Oxford, além de uma seleção internacional com materiais em português. [Ver cursos pelo mundo](https://limaronaldo.github.io/universal-ai/#cursos-mundo)
- **Se quer aplicar o que estudou**, consulte as sugestões para desenvolver um projeto, avaliar os resultados e documentar o trabalho no seu portfólio. [Explorar prática e portfólio](https://limaronaldo.github.io/universal-ai/#validacao)

As fichas apontam para as páginas de origem, onde você pode consultar a edição do material, os pré-requisitos e as condições de acesso de cada curso.

## Publicação

O GitHub Pages publica o guia automaticamente a cada push na branch `main`. A página é estática e o conteúdo principal fica em `index.html`.
